## 5. How to Run the Programs

1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal by selecting **Terminal → New Terminal**.
4. Run a Python program using the following command:

```bash
python case1.py
```

To run another program, replace `case1.py` with the desired filename.

For example:

```bash
python case2.py
python case3.py
python case4.py
```
